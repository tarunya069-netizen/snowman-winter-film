# Snowman — An Animated Winter Film

A cinematic, interactive winter animation built with HTML Canvas and JavaScript.

## Run locally

Open `index.html` in a modern browser. Use **Load the song** to select a local audio file; the film synchronizes to the selected audio and reacts to its bass. Without an audio file, it runs silently on its built-in 2:45 timeline.

## Features

- Animated snowy landscape and cinematic scene transitions
- Play, pause, seek, and fullscreen controls
- Optional local audio loading with audio-reactive visuals
- Responsive 16:9 presentation

No audio file is included; users select their own audio locally.
